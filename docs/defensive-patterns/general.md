# 通用防御模式

适用于任何 artifact 的时序、所有权、生命周期与迁移规则。

## 让正确性显式化

- **时序不承载正确性。** 不靠 sleep、轮询间隔或"应该已经完成"来保证顺序;用显式的 Promise、事件或状态转换表达完成。
- **异步状态不是同步状态。** 状态先就绪再对外可见;`await` 期间可被取消的路径必须处理取消;发布之后不得再用过期的本地快照。
- **可选输入说明两种行为。** 参数缺失时会发生什么,要写进契约并测试,而不是靠调用方猜。

## 一个值陈述一个事实

- **单一真相来源。** 同一事实不要在状态、缓存、展示层各存一份;派生值从权威来源计算。
- **共享状态只有一个主人。** 共享状态挂在服务或实例上;禁止新增模块级可变缓存、单例、`globalThis`/`window.__X__` 或 `Symbol.for` 旁路来隐藏主人。需要上下文时从当前作用域派生。
- **变更面等于评审面。** 重构只搬代码不改行为;行为变更与格式重排分开提交,否则评审无法判断哪一行改变了语义。

## 能力与扩展点归属

- **先判断必要性,再决定归属。** 新增一个区分、字段或适配器之前,先确认它真的需要;把不必要的概念换一个家,不会消除它的维护成本。
- **就近扩展。** 需要的行为优先放在离生产者或消费者最近的既有扩展点;本地实现只增加少量复杂度时,不要为它新建一层抽象。
- **共同义务归共享持有者。** 所有消费者都必须遵守的义务放在共享持有者那里,不在各消费端重复实现。

## 生命周期与释放

- **注册必须可清理。** 每个 listener、订阅、连接、定时器、worker 的注册返回 disposer;dispose 幂等;进程重启与测试隔离时,模块重新加载不得叠加旧注册。
- **释放到静默。** teardown 停止新回调、断开 listener、恢复全局钩子、终止自有工作,并等待子进程与服务关闭完成——只请求释放不算释放。
- **失败路径也清理。** 资源创建后立即登记清理;断言失败、重试与超时同样释放。

## 回调与子进程

- **回调包含。** 回调内的错误独立上报,不让一个回调的异常破坏其他回调或吞掉后续通知。
- **等待真实完成信号。** `kill`/`close` 之后要 await 退出信号,不能只调用不等待。
- **超时必须兜底。** 外部进程与外部调用都有超时;超时后清理进程树与连接。
- **不把不可信输出交给环境。** 外部输出不直接进 shell、不拼进可预测路径、不被当成配置或命令。

## 错误与迁移

- **空的 `catch` 命名错误。** 注释说明它吞掉了什么、为什么没有别的路径能到这里;`try` 保持单语句。
- **错误处理有主人。** 失败要区分"可恢复并继续"与"停止依赖工作";只有受影响状态的拥有者才能判定可以安全继续,记录日志本身不是恢复。最终报告要可读、指明受影响操作与安全的下一步([error-handling](../../.agents/skills/error-handling/SKILL.md))。
- **迁移保留行为。** 数据或接口迁移要能重复执行、失败可回滚,并在迁移前后验证同一个可观察结果。
- **性能敏感改动带证据。** 改前后用同一 workload 测量,一次只改一个因果变量;没有端到端收益就不算优化。
