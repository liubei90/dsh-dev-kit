# 客户端组件与状态

适用于 `apps/web` 的组件、状态、effect 与用户可见反馈。

## 组件与状态

- **状态有明确主人。** 服务端数据由数据层持有并可失效;只属于一个交互的临时状态留在最近的组件里;不要把同一事实在 store、组件与派生变量里各存一份。
- **effect 只做同步。** effect 用于与外部系统同步(订阅、定时器、请求),不用于派生可以渲染期计算的值;每个 effect 有完整依赖与清理函数。
- **渲染保持纯。** 渲染期不写外部状态、不发请求、不读可变共享变量。
- **组件先复用再新增。** 已有组件或设计 token 能表达时,不新增平行实现。

## 用户可见状态

- **加载、空、错误三态都要设计。** 不能只做成功态;错误要保持已有数据可见,不要清空内容来显示错误。
- **失败报告可操作。** 说明发生了什么、影响了哪个操作、安全的下一步是什么;错误文案简短且面向用户,不暴露内部细节([error-handling](../../.agents/skills/error-handling/SKILL.md))。
- **反馈面按消息寿命选择。** 一次操作的瞬时结果用全局 toast;持续存在的情况用就地提示或空态;不要用会随面板卸载而消失的面板内提示报告失败([client-ui-ux](../../.agents/skills/client-ui-ux/SKILL.md))。
- **文案走 i18n 字典。** 标题、按钮、占位符、无障碍名称都来自字典;组件里不硬编码用户可见文本。

## 交互与可访问性

- **键盘可达。** 每个交互元素可聚焦、可用键盘操作,并有可见焦点;自定义控件补齐 `role`、状态与名称。
- **移动端与窄视口。** 在 390 CSS px 下不出现意外重叠、裁切、整页横向滚动或不可达的主操作;hover 效果只在支持悬停的设备上启用([responsive-ui](../../.agents/skills/responsive-ui/SKILL.md))。
- **截断不丢关键信息。** 被截断的内容要能在别处完整看到;错误与关键状态不因截断而消失。

## 测试

- **经真实挂载测试。** 用 testing-library 渲染真实组件并断言用户可见结果(角色、名称、文案、焦点),不测内部实现或快照结构。
- **异步交互等状态。** 等待可观察状态变化,不用固定 sleep;失败的请求路径与成功路径都要覆盖。
- **客户端校验只为体验。** 表单的权威校验在服务端;客户端校验不替代它。
