# AGENTS.md — Agent Notes

Agent Notes 是代理写的 RFC：保留理由、备选方案、后果与所需验证的持久提案与决策记录。遵循[文档标准](../../docs/AGENTS.md)与 [Agent Note 规则](README.md)。

**每写一篇新笔记都要做一次取代检查。** 在活跃树里搜索覆盖同一决策或机制的旧笔记，按 [archive-agent-notes](../skills/archive-agent-notes/SKILL.md) 判断完全取代或部分取代，并在同一个 PR 里归档所有符合条件的已实现笔记。部分取代的笔记保持活跃并互相链接。

[`archived/`](archived/AGENTS.md) 下的文件是冻结的历史快照：永不编辑，也不作为当前行为的依据。
